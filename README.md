# ⚡ 分组 · GROUP//SPLIT

一个**亮色多巴胺配色**的在线随机分组工具：粘贴名单，设置每组人数，一键洗牌分组；还能把词库按组分配成「分词」，生成一个链接，每个人只看到自己的那一个词。

🔗 **在线体验**：https://dt2027.github.io/group-split/
🔑 **分词**：https://dt2027.github.io/group-split/words.html

## ✨ 功能

- **洗牌分组**：先把名单随机打乱，再按「每组人数」依次成组 —— 每组满员，最后一组拿剩余的人，随机性完全来自洗牌，各组人数最多相差 1
- **两种分组模式**：
  - **按每组人数**：只填一个数字，组数自动算（如 16 人每组 5 人 → 5 / 5 / 5 / 1）
  - **按组数自定义**：先填分组个数，再逐组填人数（第 1 组 3 人、第 2 组 13 人），支持「平均分配」一键均分；指定人数与名单人数对不上时，实时提示「超出 N 人，后面的组会自动少分」或「还剩 N 人进入未分组」
- **自由设置每组人数**：直接填人数，实时预览「将分成几组、各组几人」
- **自动去重**：重名只算一人（忽略大小写与空格），并提示去重数量
- **手动微调**：拖动成员卡片到别的组，或点 `⇄` 选择目标组；成员可移入「未分组」池；组名可改；支持新增空组、删除组、单组乱序
- **历史记录**：每次分组自动存档，可随时一键「恢复」那一次的分组结果
- **一键复制**：把分组结果按纯文本复制到剪贴板
- **🔑 分词**：沿用当前分组结果，导入词库后按组分配词语，生成分发链接；参与者打开链接、输入姓名即可领取**专属于他/她的那一个词**
  - **词库导入**：`.xlsx`（每个单元格 = 一个词，读取全部工作表的全部非空单元格）、`.csv` / `.txt`，或直接粘贴（每行一个词）
  - **分配规则**：每组独立抽词，**组内互不相同、组间可重复**；某组人数大于词库词数时会拦截发布并提示补充词库
  - **前端只显示自己的词**：参与者界面仅显示本人姓名对应的那个词与所在组
  - **数据不出浏览器**：词库与分配结果经 gzip 压缩后编码进链接的 `#` 片段（fragment 不会发往服务器），全程零后端
- **本地保存**：名单、分组结果与历史记录都存在浏览器 localStorage，刷新不丢、不上传任何服务器
- **响应式**：手机、平板、桌面都能正常使用
- **亮色界面**：浅紫白底 + 高饱和多巴胺霓虹描边，白天看不刺眼

## 🛠 技术栈

纯静态页面，零依赖、零构建：HTML + CSS + 原生 JavaScript。

随机数优先使用浏览器原生 `crypto.getRandomValues()`（不可用时回退到 `Math.random()`），洗牌使用 Fisher–Yates 算法，整个分组过程完全在本地完成。

分词页另外按需加载 [SheetJS](https://sheetjs.com/)（`vendor/xlsx.full.min.js`，Apache-2.0），**只有选择 `.xlsx` 文件时才会下载**，平时使用不产生任何额外请求。

链接里的分配数据用浏览器原生 `CompressionStream('gzip')` 压缩后转 base64url 编码进 URL 的 `#` 片段 —— fragment 部分不会随 HTTP 请求发送，因此词库和分配结果**不会经过任何服务器**。

## 🚀 本地运行

直接双击 `index.html` 即可使用；或用任意静态服务器：

```bash
# 任选其一
npx serve .
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 🔄 修改后重新发布

GitHub Pages 对静态资源统一返回 `Cache-Control: max-age=600`（缓存 10 分钟）。因此修改 `styles.css` / `app.js` 后，请同步把 `index.html` 里的版本号改掉，浏览器即可立刻拿到新版本：

```html
<link rel="stylesheet" href="styles.css?v=7" />
<script src="app.js?v=7"></script>
```

`words.html` / `words.js` 同样带版本号，发布新版本时一并提升即可。

## ⌨️ 使用流程

1. 在左侧「名单」框粘贴或输入名字（每行一个，也支持逗号 / 顿号分隔）
2. 在「分组设置」里选模式：
   - **按每组人数** —— 填每组人数，组数自动算
   - **按组数自定义** —— 填分组个数，再逐组填人数，或点「平均分配」
3. 点击「开 始 分 组」（或在名单框按 `Ctrl` + `Enter`）
4. 结果出现在右侧；不满意可点「重新分组」再洗一次
5. 需要微调时，拖动成员卡片，或点成员右侧的 `⇄` 移动到指定组

## 🔑 分词使用流程

**组织者**（在分组页完成分组之后）：

1. 点页头的「🔑 分词」进入 `words.html`，页面会自动读取当前分组结果（与分组页共用同一份 localStorage）
2. 导入词库：上传 `.xlsx`（每个单元格 = 一个词）或 `.csv` / `.txt`，也可以直接粘贴（每行一个词，自动去重）
3. 点「生成分发链接」，得到一条 `words.html#room=...` 的链接；页面下方会显示完整的分配结果预览
4. 把这条链接发给参与者

**参与者**：

1. 打开链接，页面自动进入领取视图
2. 输入自己的姓名（须与名单一致），点「查看我的词」
3. 页面只显示分配给你的那一个词和所在组名

> ⚠️ 说明：分配数据编码在链接的 `#` 片段里，拿到链接的人技术上可以自行解码查看全部词表。本工具面向的是「不便互相看屏幕」的普通聚会场景，界面层面已做到各看各的。
